# promesas-js

Proyecto educativo con cuatro buscadores de API REST usando HTML, CSS, JavaScript, `fetch()` y `async/await` (promesas).

## Ejecutar
1. Descomprime la carpeta.
2. Abre `index.html` en un navegador, o abre la carpeta en VS Code y ejecútala con la extensión Live Server.
3. Necesitas conexión a Internet para consultar las API.

## Ejercicios
1. Planetas SWAPI: nombre, clima, terreno, población y gravedad.
2. Naves SWAPI: nombre, modelo, fabricante, costo y velocidad máxima.
3. Dragon Ball API: nombre, descripción e imagen.
4. PokéAPI: nombre, ID, experiencia, altura, peso, tipos e imagen.

## Antes de entregar
- Prueba cada buscador, incluidos IDs inválidos.
- Toma capturas reales de la aplicación en funcionamiento.
- Sube el proyecto a tu repositorio GitHub y añade la URL real al informe.
- Exporta el informe con capturas a PDF. La actividad pide entregar únicamente el PDF.
